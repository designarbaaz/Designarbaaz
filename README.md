# ✦ Designarbaaz — Senior Product Designer Portfolio

Interactive, responsive portfolio website for **Md Arbaaz**, Senior Product Designer.

Live Website: [https://designarbaaz.github.io/Designarbaaz/](https://designarbaaz.github.io/Designarbaaz/)

---

## 📂 Project Overview

- **`index.html`**: Main portfolio showcase featuring hero section, interactive work cards with 3D cursor tilt & dynamic spotlight glow, client marquee, interactive pill badges, and sticky navigation.
- **`case-study.html`**: In-depth UX case study for **Kajaria Ceramics** (modernizing digital catalogue & mobile experience).
- **`case-study-2.html`**: In-depth UX case study for **Hero Homes** (luxury real estate digital branding & interactive property discovery platform).
- **`assets/`**: 100% self-hosted zero-dependency assets (Inter & Instrument Serif webfonts, high-resolution media, walkthrough videos, SVGs).
- **`.nojekyll`**: Enables direct static file serving on GitHub Pages without Jekyll processing.

---

## 🚀 Running Locally

```bash
python3 serve.py
```
Or start any standard HTTP server:
```bash
npx serve .
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
